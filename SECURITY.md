# Security

Signals runs on your Mac and reads local files: your agents' session logs and their saved usage. It never uses your AI accounts' logins and sends nothing anywhere. Admin keys, if you add one for account-wide cost reports, are stored in the macOS Keychain.

If you find a security problem, please report it privately through GitHub's **Report a vulnerability** button on this repository's Security tab, rather than in a public issue. You'll get a reply within a few days.
